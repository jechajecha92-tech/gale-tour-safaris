# Your own photos go here

The website automatically shows a photo for each activity if a file with the
matching name below is in this folder. Upload as MANY as you like — there is no
limit. Any activity without a photo yet shows a temporary stand-in (never blank).

## How to add photos (you can do many at once)
1. On your phone/computer, rename each photo to the **exact** file name in the
   table below (all lowercase, ending in `.jpg`).
2. Go to your GitHub repo -> `assets` -> `img` folder.
3. Click **Add file -> Upload files**, then drag in ALL your photos together.
4. Click **Commit changes**. Netlify redeploys in ~1 minute and they appear.

Tip: keep photos landscape (wide) and under ~500 KB each so the site stays fast.
