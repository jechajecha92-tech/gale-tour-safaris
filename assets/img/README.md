# Your own photos go here

Drop your real photos in this folder using these EXACT file names (all lowercase,
.jpg). As soon as a file is here, it appears on the website automatically.
Until then, the site shows a temporary stand-in photo (never blank).

| File name to use        | Where it appears on the site            | Photo to use                                  |
|-------------------------|-----------------------------------------|-----------------------------------------------|
| `nakupenda.jpg`         | "Nakupenda Island Tour" card            | The wooden boat full of tourists on the sea   |
| `mnemba.jpg`            | "Mnemba Snorkeling" card                | The aerial green island with white sandbank   |
| `prison-island.jpg`     | "Prison Island Tour" card               | The giant tortoise photo                       |
| `stone-town.jpg`        | "Stone Town Tour" card + home gallery   | The aerial Stone Town / waterfront photo       |

## To add more photos later
1. Put the image file in this folder (e.g. `spice-tour.jpg`).
2. In `assets/app.js`, find the `LOCAL_IMG` list near the top and add a line, e.g.
   `"Spice Tour": "spice-tour.jpg",`
That's it — the card will use your photo.

Tip: keep photos roughly landscape (4:3) and under ~500 KB each so the site stays fast.
