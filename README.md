# Gale Tour and Safaris

A production-quality, single-file static website for **Gale Tour and Safaris** — a Zanzibar-based tourism and transfer company.

## Files
- `gale-tour-safaris.html` — the complete site (inline CSS + JS, no build step). Open directly in any browser.
- `assets/` — folder for site images.

## Features
- Custom Zanzibar coastal OKLCH palette (deep ocean teal + golden sunset), light & dark mode toggle.
- Instrument Serif + Plus Jakarta Sans typography, custom inline SVG dhow-sail logo & favicon.
- Sticky blurred nav, mobile slide-in menu, 28 filterable excursion cards (Lucide icons), transfer zones, contact section, floating WhatsApp button.
- Fully responsive, semantic HTML5, WCAG AA, scroll-reveal animations honoring prefers-reduced-motion.
